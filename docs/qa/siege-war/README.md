# 2대2 3라인 공성전 QA 캡처

모두 실제 서버 판정 경기를 실행해 촬영했다. 3D 전장은 WebGL 캔버스에서,
상단 HUD·성문 HP·하단 소환 카드는 같은 프레임 위에 합성해 실제 화면과 동일하게 만들었다.
기본 해상도는 `393×760`(DPR 2 → 786×1520)이다.

| 파일 | 장면 | 확인 사항 |
|---|---|---|
| `01-opening.png` | 경기 초반 | 3라인, 양 팀 성문 3개씩, 소수 병력 전진 |
| `02-midgame-clash.png` | 중반 물량전 | 세 라인 모두 교전, 궁수 후방 배치, 양 팀 색 구분 |
| `03-single-lane-push.png` | 한 라인 집중 | 중앙에 병력·공성추 집중, 해당 성문 HP 280까지 감소, 나머지 라인은 한산 |
| `04-total-assault.png` | 총공세 | 남은 시간 60초에 배너 노출, 병사·궁수 카드가 `무제한`으로 전환 |
| `05-late-crush.png` | 극후반 물량전 | 동시 122기에서도 3라인·양 팀·성벽이 모두 판별 가능 |

## 촬영 방법

`?debug=1`로 접속한 디버그 방(BOT 좌석이 있는 방)에서만 동작하는 연출 명령으로
장면을 만들었다. 명령은 전부 서버에서 실행되고, 이후 진행은 일반 경기와 완전히 같은
시뮬레이션을 거친다.

```
{ op: "clash", lane, count }              // 한 라인에 count 대 count 배치
{ op: "fill", team, lane, unitType, count }
{ op: "clear" }                            // 전 병력 제거 + 성문 회복
{ op: "clock", remainingMs }               // 남은 시간 이동 (총공세 자동 반영)
{ op: "gate", team, lane, hp }
{ op: "assault" } / { op: "sudden" }
{ op: "bots", enabled }                    // 연출 중 BOT 정지
```

## 이 캡처로 확인한 규칙

- 성문은 팀당 3개, 각 `1000`. 상단 HUD는 합계 `3000`을 표시하지만 승패는 합계가 아니라
  **성문 하나라도 0이 되면 즉시 패배**다.
- 총공세는 남은 시간 60초에 시작하며 병사·궁수만 `무제한`이 되고 공성추는 `5.5초`를 유지한다.
- 풀 HP 유닛에는 체력바가 없고, 피해를 입은 유닛에만 머리 위에 얇은 바가 나타난다.
- 미러링은 씬 루트 180° 회전 하나로 처리한다. 빨간팀 화면에서는 빨간 성벽이 아래로 오고
  좌우도 함께 반전된다. 상단 팀 라벨은 절대 팀 정체성이라 뒤바뀌지 않는다.
