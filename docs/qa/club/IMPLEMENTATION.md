## 규칙/상태

- 정확히 4인. 오목/알까기는 동시 준결승 → 동시 결승/3·4위전 또는 2대2 교대 팀전.
- 팀 편성: 랜덤 또는 방장이 빨강 두 명 직접 지정. 팀당 5알 공유. 팀원 순서는 선택/등록 순서.
- 무승부: 해당 경기 참가자 전원 재경기 준비 후 자동 초기화, 선공 교체. 인게임 임의 초기화/무르기 없음.
- 결과의 재대결은 공용 준비 화면으로 이동. 동일 명단 재대결은 선공 교체. 다른 게임 선택/로비로 나가면 기존 방 정책에 따라 이전 경기 종료.
- 알까기는 서버가 입력 힘/돌 소유권을 검증하고 전체 충돌/감속/탈락을 확정, 결과 좌표와 애니메이션 프레임을 공유. 클라이언트 물리 결과 수신 없음. 대칭 고정 장애물은 설정에서 ON/OFF, 기본 OFF.
- 숫자야구는 서버 비밀 숫자 하나. 전원/양 팀 동시 입력, 모두 제출할 때만 판정. 같은 라운드 정답 공동승/팀 무승부. 시도 횟수 제한 없음. 비밀 숫자는 결과를 포함해 직렬화하지 않음.
- 개인 기록은 본인만, 팀 기록은 팀원만. 상대는 제출 여부만 알 수 있음. 팀 입력 담당은 매 라운드 교대. 팀원 상의는 현장 대화로 가능.
- 정답/진행/제출/차례의 타이머 없음. 숨김/접속 끊김은 자동수/AI로 대체하지 않음. 30분 참가자 정리에서 진행 중 명단 보존. 명시적 퇴장은 자리와 세션을 보존한 채 경기 일시정지, 동일 쿠키의 재참가 시 재개. 기존 방의 8시간 비활성 만료 정책은 유지.
- 경기 UUID + match ID + 재경기 회차 + 턴/숫자 라운드 + request UUID 검증. 경기 동안 처리한 요청 번호 보존. D1 CAS 충돌은 기존 클라이언트 재시도로 처리.
