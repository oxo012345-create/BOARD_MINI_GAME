# 개인별200기 밸런스 검증

모든 플레이어의 살아 있는 히드라를 각각200기로 제한한다. 성큰·대군주는 제외하며 아군/탈락자의 여유 한도를 빌릴 수 없다. 상한에 도달한 플레이어만 증원을 멈추고 손실 후 정상 생산 주기에 재개한다. 원작 RULES는 보존하고 모바일 프로필에 적용했다.

AI는 사격 가능한 위협을 요격하며 먼 적 때문에 아군 거점 중앙으로 후퇴하지 않는다.8초간 이동·처치·교전에 진전이 없으면10초간 공격 목표를 우선한다. 교전 중인 정지 병력은 교착으로 판단하지 않는다. 사람/AI의 자원과 전투 수치는 같다.

시작1000, 점령250, 강화50, 거점별1.302초 생산, 구역80기 제한, 성큰HP8000/공격200, 기존 처치/파괴 보상을 유지했다. 성큰 체력 하향은 이번 결과에서 필요하지 않아 적용하지 않았다.
