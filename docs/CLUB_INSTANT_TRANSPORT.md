# 오목·알까기 입력 전달

기존 D1 판정/저장과 long-poll 복구는 유지한다. 두 게임에만 별도
`hanpan-club-input` Worker/DO를 추가하며 기존 Worker, 게임, DB 스키마,
Sites 바인딩은 수정하지 않는다. Sites의 새 CLUB_INPUT_URL/CLUB_INPUT_SECRET
환경변수만 사용한다. 비밀 값은 저장소에 기록하지 않는다.

참가 쿠키로 발급한 짧은 서명 티켓으로 연결한다. 연결은 20초마다 재인증하고
60초 이내 만료한다. 발사/착수 의도만 작은 WebSocket 메시지로 전달한다.
수신자는 현재 경기·재경기·턴·행위자·렌주 금수·돌 소유권을 검증한다.
화면에서만 예측하며 턴, 승패, 결과, 영속 상태는 기존 서버 응답으로 확정한다.
실패 취소와 5초 만료 시 원상 복구하고, 확인 응답은 애니메이션을 재시작하지 않는다.
상대는 예측 상태에서 다음 행동을 할 수 없다. 연결 불가/백그라운드 복귀 시
기존 HTTP 경로로 계속 플레이한다. 알까기 FRAME_MS/물리 계수는 변경하지 않는다.

Worker는 방+경기별로 분리하고 APAC 배치 힌트를 사용한다. 연결된 참가자만
자기 ID로 입력을 전송하며, 크기/빈도 제한과 동일 턴 중복 억제를 적용한다.
통신 경로는 실제 배포판 4개 세션으로 기존 HTTP 도착 시간과 비교한다.
