# 황혼의 콩시장 UI V3 확정 사양

이 문서는 밝은 농장 UI 전면 재설계의 시각·조작 기준이다. 기존 황혼/서부 UI를 리스킨하지 않고 화면 구조와 오브젝트를 새로 제작한다.

## 5인 기본 화면

1. 상단: 방 번호 / 현재 단계 / 설명 / 옵션
2. 상대: 플레이어 1·2 / 플레이어 3·4의 카드, 코인, 손패 수, 밭
3. 중앙: 뽑기 더미, 버린 더미, 공개 카드 2장
4. 하단: 내 플레이어 카드, 내 밭 1·2, 손패
5. 배경 위에 꼭 필요한 게임 오브젝트만 둔다. 과도한 프레임, 장식, 설명 패널은 사용하지 않는다.

## 카드와 밭

- 카드 종류는 강낭콩 6장, 팥 8장, 동부 10장, 대두 12장, 완두콩 14장, 똥콩 16장, 칠리콩 18장, 푸르대콩 20장이다.
- 손패 카드는 한글판 보난자의 콩별 색상·개성을 참고한 독립 PNG 8종으로 제작한다.
- 내 밭에는 콩나무 한 그루만 보인다. 실제 카드 수만큼 열매를 1~9개까지 표시하고, 10개 이상도 화면에는 9개까지만 보인다.
- 밭 아래에는 `콩 종류 ×n개`를 표시한다.
- 상대 밭은 종류 그림을 고정하고 수량은 `×n개` 텍스트로만 표시한다.

## 거래 팝업

- 거래 단계에 플레이어 카드를 누르면 열린다. 현재 턴 플레이어가 포함된 거래만 신청할 수 있다.
- 공개 카드 위부터 손패 위까지 대부분을 가리되 바깥 기본 UI가 조금 보이는 큰 팝업으로 만든다.
- 상대 영역과 내 영역은 각각 8칸이며 같은 콩 2장 이상은 한 카드와 `×n개`로 묶는다.
- 하단에는 거래 거절 / 거래 승인 조작만 둔다.
- 거래 중 화면 순서는 거래 UI / 공개 카드 / 내 손패다.

## 드래그와 터치

- 약 0.15초 길게 누르면 드래그를 시작한다. 짧은 터치는 선택 방식으로 동작해 스크롤과 충돌하지 않는다.
- 드래그 카드는 손가락 위쪽에 확대해 표시한다.
- 심기 단계에는 손패 첫 카드만 드래그할 수 있다. 가능한 밭은 금빛, 불가능한 밭은 어둡게 표시한다.
- 거래 단계에는 모든 손패와 공개 카드를 거래판의 내가 주는 영역으로 드래그할 수 있다. 거래판에서 손패 방향으로 되돌리면 취소한다.
- 받은 콩 심기 단계에는 받은 콩과 남은 공개콩만 원하는 순서로 드래그할 수 있고 기존 손패는 잠근다.
- 화면 좌우 끝에서는 손패를 자동 스크롤하고, 놓을 위치 근처의 밭/거래판을 확대한다.
- 성공은 진동 1회와 심기 애니메이션, 실패는 짧은 진동과 원위치 애니메이션으로 알린다.
- 손패 드래그로 카드 순서를 바꾸지 않는다. 서버 성공 응답 전에는 카드를 제거하지 않는다.
- 드래그가 어려운 사용자를 위해 카드 터치 → 밭 터치를 항상 함께 지원한다.
