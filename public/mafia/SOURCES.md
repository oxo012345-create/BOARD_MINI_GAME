# Mafia audio sources

- `night-bgm.mp3` — [Darkest Hour](https://opengameart.org/content/darkest-hour), OpenGameArt, CC0.
- `day-bgm.mp3` — [CC0 Mystery](https://opengameart.org/content/cc0-mystery), OpenGameArt, CC0.
- `gunshot.ogg` — [Gunshots 8](https://commons.wikimedia.org/wiki/File:Gunshots_8.ogg), Wikimedia Commons, public domain.

The gunshot is played only when the server reports an actual night victim. Quiet nights, missing attacks, and doctor-protected attacks do not play it.
