# 휴대폰 전용 오프라인 토론형 경매 웹게임

문서 버전: 1.1  
가칭: **오늘의 호구왕**

## 1. 최종 게임 형태

3~8명이 같은 장소에 모여 각자의 휴대폰으로 접속한다. 대화와 토론은 얼굴을 보고 직접 하며, 웹은 카드·입찰·돈 계산·상점·결과 공개만 담당한다.

```text
플레이어 A 휴대폰 ─┐
플레이어 B 휴대폰 ─┤
플레이어 C 휴대폰 ─┼─ 같은 웹 방
플레이어 D 휴대폰 ─┘

별도 TV, 태블릿, 진행자, 음성 채팅 없음
```

각 휴대폰은 두 역할을 동시에 한다.

- **공용 정보:** 아이템, 최고 입찰가, 타이머, 순위, 폭로 결과
- **개인 정보:** 내 돈, 내 카드, 내 아이템, 판매자만 보는 실제 가치와 조항

권장 인원은 4~6명, 한 판은 15~25분이다.

---

## 2. 가장 자연스러운 이용 흐름

### 방 만들기

한 명이 사이트에 접속해 `방 만들기`를 누른다.

- 닉네임 입력
- 인원 제한 3~8명
- 1~3라운드
- 경매 시간 30/45/60초
- 일반 모드/술자리 모드
- 카드 상점 사용 여부

방을 만들면 다음을 보여준다.

- 4자리 방 코드
- 초대 링크 복사
- QR 코드
- 카카오톡 등으로 공유 버튼

QR은 방을 만든 사람의 휴대폰에 표시하고 다른 사람들이 스캔한다. QR 스캔이 불편하면 방 코드 또는 초대 링크를 사용한다.

### 참가

다른 사람은:

1. 초대 링크를 누르거나 사이트에서 방 코드 입력
2. 닉네임 입력
3. 패들 색상 선택
4. 준비

회원가입과 앱 설치는 요구하지 않는다.

### 시작

- 3명 이상이 준비하면 방장에게 `게임 시작` 버튼 표시
- 시작 후 서버가 판매 순서를 무작위 결정
- 모든 휴대폰에 판매 순서 표시
- 현재 판매자의 휴대폰이 진동

## 3. 플레이 중 휴대폰 사용 원칙

모든 사람이 같은 장소에 있으므로 화면만 쳐다보게 만들면 안 된다.

- 정보를 확인하는 시간과 직접 대화하는 시간을 분리한다.
- 토론 중에는 큰 아이템 그림, 타이머, 입찰 버튼만 남긴다.
- 긴 설명은 판매 준비 또는 폭로 단계에서만 보여준다.
- 중요한 변화는 진동과 짧은 효과음으로 알린다.
- 한 손으로 조작 가능하도록 주요 버튼을 화면 아래에 둔다.
- 플레이어가 자기 화면을 남에게 보여주는 것은 자유다.
- 판매자가 비밀정보를 직접 보여줘도 규칙 위반으로 막지 않는다. 그것도 협상 전략이 될 수 있다.

## 4. 한 판의 진행

### 4.1 라운드 시작

모든 휴대폰에:

- 현재 라운드
- 이번 라운드 시장 유행
- 판매 순서
- 5초 카운트다운

예:

- 유물 최종 가치 +20%
- 기계류 즉시 판매 가치 -15%

### 4.2 판매자 아이템 선택

판매자 화면:

- 후보 아이템 3장
- 각 아이템 실제 가치
- 숨은 조항 2개
- `이 물건 판매` 버튼

다른 사람 화면:

- “민수가 물건을 고르는 중”
- 남은 시간
- 내 돈과 카드 확인

20초 안에 고르지 않으면 자동 선택한다.

### 4.3 판매 준비

판매자에게만 10초 동안 비밀 장부를 크게 보여준다.

- 실제 가치
- 조항 2개
- 조항 발동 시점
- 예상 손익
- 초보자를 위한 허풍 예시 1개

예:

```text
실제 가치: 180
조항 1: 구매자가 현재 꼴찌면 가치 +200
조항 2: 판매 수수료 15%

추천 멘트: “이건 지금 하위권인 사람이 사면 특히 좋을 수도 있어.”
```

### 4.4 현장 토론

모든 휴대폰에 공통으로:

- 아이템 그림
- 이름과 공개 설명
- 분류
- 타이머
- 현재 최고가

판매자 화면 오른쪽 위에는 작은 `비밀 장부` 버튼을 둔다. 누르고 있는 동안에만 비밀정보를 다시 보여줘 옆 사람이 우연히 보지 않게 한다.

모두 현장에서 자유롭게 질문하고 거짓말한다. 웹 채팅과 음성 기능은 없다.

### 4.5 입찰

구매자 화면 하단:

- `+10`
- `+50`
- `+100`
- `직접 입력`
- `이번 경매 포기`

판매자 화면:

- 입찰 버튼 없음
- 현재 최고가와 최고 입찰자
- 예상 판매 수익

입찰이 들어오면 모든 휴대폰에서:

- 최고가 숫자가 튀어 오름
- 입찰자 색상의 패들이 1초간 표시
- 짧은 코인 효과음

마지막 3초에 새 입찰이 들어오면 3초 연장하며 최대 2회 적용한다.

### 4.6 폭로

모든 휴대폰이 동시에 같은 폭로 애니메이션을 재생한다.

1. 낙찰자와 낙찰가
2. 화면 탭을 요구하는 1초 정지
3. 실제 가치
4. 조항 1
5. 조항 2
6. 구매자 손익과 판매자 수익
7. 전체 순위 변화

효과음은 각 휴대폰에서 동시에 나면 시끄러우므로 다음 설정을 둔다.

- 방장은 시작 전에 `모든 기기 소리` 또는 `방장 기기만 소리` 선택
- 기본값은 `방장 기기만 소리`
- 나머지 기기는 진동과 애니메이션만 사용

### 4.7 다음 판매자

- 결과 확인 후 전원에게 `확인` 버튼
- 절반 이상이 확인하거나 10초가 지나면 자동 진행
- 다음 판매자 휴대폰 진동

### 4.8 시장/상점

모든 사람이 한 번씩 판매하면 45초간 시장 단계.

각 휴대폰에서:

- 내 아이템 즉시 판매
- 계속 보유
- 카드 구매
- 다른 플레이어에게 거래 제안

상단에는 전체 공용 정보:

- 각 플레이어 현금
- 보유 아이템 개수
- 현재 순위
- 시장 유행

시간 안에 고르지 않은 아이템은 자동 보유한다.

### 4.9 최종 결과

모든 휴대폰에 같은 순위를 표시한다.

- 3위부터 공개
- 최종 자산
- 가장 큰 이익
- 가장 큰 손해
- 최고의 허풍쟁이
- 최고의 호구
- 가장 짠 입찰자
- 술자리 모드 선택형 벌칙

`같은 멤버로 다시 하기`는 투표로 결정한다. 과반수가 누르면 바로 새 게임을 만든다.

## 5. 화면 콘티

### M01. 홈

- 로고
- `방 만들기`
- `방 참가`
- `게임 방법`
- 최근 방 재접속

### M02. 방 만들기

- 라운드, 시간, 모드, 카드 설정
- 방장 기기만 효과음 여부
- `생성`

### M03. 초대 로비

- 상단: 4자리 코드
- 중앙: QR
- `링크 공유`
- 하단: 참가자 목록과 준비 상태
- 고정 하단: `게임 시작`

### M04. 방 참가

- 큰 숫자 키패드
- 방 코드 4칸
- 닉네임
- 패들 색상
- `입장`

### M05. 판매 순서

- 플레이어 카드가 세로로 정렬
- 내 이름에 `나` 표시
- 현재 판매자 강조
- 5초 후 자동 전환

### M06-S. 판매자 선택

- 후보 3개를 세로 카드로 표시
- 각 카드에 그림, 실제 가치, 조항
- 하단 `선택`

### M06-B. 구매자 대기

- 현재 판매자 프로필
- “물건을 고르는 중”
- 내 돈/카드 바로가기
- 대기용 짧은 질문 예시

### M07-S. 판매자 비밀 장부

- 화면 상단에 `다른 사람에게 보여주지 마세요`
- 실제 가치
- 조항 2개
- 판매 팁
- `준비 완료`

### M07-B. 공개 아이템

- 큰 아이템 그림
- 이름과 공개 설명
- “판매자가 정보를 확인 중”

### M08. 토론/입찰

공통 상단:

- 아이템 축소 이미지
- 이름
- 45초 타이머

공통 중앙:

- 현재 최고가
- 최고 입찰자
- 최근 입찰 2건

구매자 하단:

- `+10`, `+50`, `+100`
- 카드
- 포기

판매자 하단:

- 예상 판매 수익
- 누르고 있을 때만 보이는 `비밀 장부`

### M09. 폭로

- 카드가 화면 전체를 덮음
- 탭할 때마다 가치 → 조항 → 손익 공개
- 개별 탭 속도가 달라도 서버 단계에 따라 2초 후 자동 진행

### M10. 시장

- `내 아이템` 탭
- `카드 상점` 탭
- `거래` 탭
- 상단에 45초 타이머
- 하단에 `선택 완료`

### M11. 결과

- 순위
- 칭호
- 선택형 벌칙
- `재대결 투표`
- `나가기`

## 7. 카드 상점

카드는 게임 안의 돈으로만 산다.

| 카드 | 가격 | 효과 |
|---|---:|---|
| 돋보기 | 100 | 조항 하나의 긍정/부정만 확인 |
| 감정서 | 150 | 실제 가치가 300 이상인지 확인 |
| 자동 입찰 | 100 | 지정 상한까지 +10 자동 입찰 |
| 시간 연장 | 100 | 토론 시간 10초 연장 |
| 계약 파기 | 220 | 자신에게 적용된 조항 하나 취소 |
| 보험 증권 | 150 | 이번 구매 손실 최대 150 보전 |
| 반사 도장 | 200 | 자신을 향한 카드 효과 반사 |
| 강제 공개 | 250 | 실제 가치의 최솟값 공개 |
| 입찰 봉쇄 | 180 | 한 명이 5초간 입찰 불가 |
| 급전 대출 | 0 | 250 획득, 종료 때 330 상환 |
| 시장 소문 | 120 | 다음 시장 인기 분류 확인 |
| 창고 이용권 | 100 | 유지비 한 번 무효 |

판매자의 거짓말을 카드 한 장으로 완전히 파악할 수 없게 한다.

## 8. 술자리 모드

음주를 강요하지 않고 `벌칙 카드`를 선택적으로 제공한다.

- 다음 경매에서 존댓말만 사용
- 물건의 광고송 만들기
- 판매자를 10초간 칭찬
- 다음 설명을 뉴스 앵커처럼 하기
- 한 턴 동안 말끝에 “입니다요” 붙이기
- 가장 큰 손해를 본 이유를 인터뷰 형식으로 설명
- 본인이 원할 경우 음료 한 모금 또는 물 마시기

방 설정에서:

- 벌칙 없음
- 말하기 벌칙만
- 행동 벌칙 포함
- 음료 선택지 포함

신체 접촉, 모욕, 과음, 개인정보 공개를 요구하는 벌칙은 넣지 않는다.

| 배포 | Cloudflare Pages |
| 이미지/효과음 | Cloudflare R2 |
| 설치형 웹 | PWA |
| 익명 통계 | 필요할 때 Cloudflare D1 |

게임 엔진은 사용하지 않는다. 이 게임은 2D 카드 UI, 숫자, 타이머, 애니메이션이 중심이므로 일반 웹 기술이 가장 적합하다.

### 서버가 관리하는 상태

```text
LOBBY
→ ROUND_INTRO
→ SELLER_PICK
→ SELLER_READY
→ DISCUSSION
→ FINAL_BID
→ REVEAL_VALUE
→ REVEAL_CLAUSE_1
→ REVEAL_CLAUSE_2
→ SETTLEMENT
→ NEXT_SELLER
→ MARKET
→ NEXT_ROUND
→ RESULTS
```

서버만 결정:

- 판매 순서
- 아이템과 실제 가치
- 조항
- 현재 최고 입찰
- 타이머
- 돈, 카드, 아이템
- 최종 순위

판매자 비밀정보는 판매자의 연결에만 전송한다.

### 통신 끊김

- 재접속 토큰을 브라우저에 저장
- 30초 동안 좌석 유지
- 재접속 시 현재 단계와 개인 상태 복원
- 판매자 이탈 시 20초 대기 후 무작위 아이템 선택
- 구매자 이탈 시 자동 포기
- 시장에서 이탈하면 자동 보유

## 11. 제작 일정

1인 개발 기준 8~12주.

| 기간 | 제작물 |
|---:|---|
| 1주 | 종이 규칙 테스트, 모바일 와이어프레임 |
| 1~2주 | 방, 코드, 여러 휴대폰 접속 |
| 2주 | 판매자 선택, 토론, 입찰, 폭로 |
| 1~2주 | 시장, 카드, 정산 |
| 2주 | 아이템·조항 콘텐츠와 일러스트 |
| 1주 | 애니메이션, 효과음, 진동 |
| 1~2주 | 실제 모임 테스트와 오류 수정 |

### 첫 프로토타입

다음 7개만 먼저 만든다.

1. 휴대폰 1대로 방 생성
2. 다른 휴대폰 3대가 코드로 참가
3. 판매자만 가치와 조항 확인
4. 모든 휴대폰에 같은 아이템 표시
5. 45초 현장 토론
6. 휴대폰 입찰
7. 동시 폭로와 정산

이 상태로 실제 모임에서 최소 5판 테스트한 후 상점과 많은 아이템을 추가한다.

## 12. 핵심 성공 기준

- 참가자가 2분 안에 방에 들어오는가
- 모두 화면보다 서로 얼굴을 더 많이 보는가
- 경매마다 질문, 거짓말, 반박이 자연스럽게 나오는가
- 여러 휴대폰의 효과음이 시끄럽지 않은가
- 입찰 버튼을 잘못 누르는 일이 적은가
- 폭로 순간에 웃음이나 탄식이 나오는가
- 한 판 후 바로 재대결하는가

최종 정의:

> 별도 공용 화면 없이, 모든 참가자가 자기 휴대폰 하나만 사용하며 같은 장소에서 직접 토론하는 경매·블러핑 파티 웹게임.
